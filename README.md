# Late Night English

Eine Übungs-App fürs Handy: Ein erfundener Late-Night-Host („Danny") plaudert auf Englisch über die Nachrichten von heute, hört zu und korrigiert Fehler mit Humor.

- Läuft komplett im Browser (Android: Chrome, iPhone: Safari) und lässt sich auf den Startbildschirm legen.
- Braucht einen eigenen OpenAI-API-Schlüssel, der **nur in der App am Handy** eingetragen wird – nie hier im Code.
- Fortschritt wird nur auf dem Handy gespeichert.

Adresse: https://imitosis.github.io/late-night-english/
